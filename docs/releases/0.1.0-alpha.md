The first public build of Snail Chess GUI, an open source chess GUI written in [Snail](https://github.com/CodeAdopter/Snail). It is an alpha: expect rough edges, and please [open an issue](https://github.com/CodeAdopter/Snail-Chess-Gui/issues) for anything that goes wrong.

## Download and run

1. Download `snail-chess-gui-0.1.0-alpha-windows.zip` below and unzip it anywhere.
2. Open `Snail Chess GUI.exe` in the `Snail Chess GUI` folder.
3. The build is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

Needs 64-bit Windows 10 or 11 and a graphics card with DirectX 12. Nothing is installed: your data is kept in `%LOCALAPPDATA%\Snail Chess GUI`, or beside the app if you create an empty file named `portable` next to it.

## What's in it

- Analysis with engine lines as arrows, opening names, an evaluation graph and game review.
- Play against engines at the strength you choose, or against people on Lichess.
- Engine tournaments, and fastchess matches and SPRT tests shown live.
- Engines and opening books from their registries in a few clicks, and opening books made by your engines.
- A position database of every evaluation your engines make, and cloud evaluations shared between users.
- 2D and 3D boards, with piece sets, board styles, scenes and effects.
- [Snail Chess](https://github.com/CodeAdopter/Snail-Chess) 1.19 included, so you can play and analyze right away.

See the [README](https://github.com/CodeAdopter/Snail-Chess-Gui#readme) for the full list.
